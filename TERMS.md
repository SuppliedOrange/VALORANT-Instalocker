# Пользовательское соглашение и условия использования

**Действующая редакция:** 28 октября 2026  
**Разработчик этой сборки:** Nanda070  
**Репозиторий:** [Nanda070/VALORANT-Utils](https://github.com/Nanda070/VALORANT-Utils)
**Состав:** Instalocker и Rank Checker

Установка и нажатие «Принимаю» означают согласие с этими условиями. Текст установщика лежит в `TERMS.txt`.

## 1. Что делает программа

VALORANT Utils включает Instalocker для выбора агента и Rank Checker для отображения рангов, статистики и loadouts игроков через локальные API VALORANT. Программа не читает память игры, не меняет файлы игры и не нажимает кнопки в окне VALORANT.

## 2. Согласие

Если вы не согласны с условиями, не устанавливайте программу и закройте её.

## 3. Риск для аккаунта

Такое использование клиентского API нарушает условия Riot Games. Блокировка агента может не успеть. Автор не обещает результат и не отвечает за наказания, включая ограничение или блокировку аккаунта. Этот риск вы принимаете сами.

Программа не связана с Riot Games и не одобрена Riot Games.

## 4. Авторство

Instalocker основан на проекте SuppliedOrange. Основа Rank Stats взята из [mdevio/VALORANT-rank-yoinker](https://github.com/mdevio/VALORANT-rank-yoinker). Установщик, автообновление и эта сборка поддерживаются Nanda070.

## 5. Запреты

- Нельзя продавать программу, сдавать её в аренду или выдавать за свою.
- Нельзя удалять указание авторов.
- Нельзя добавлять вредоносный код, кражу данных или атаки на сервисы Riot.

## 6. Что хранится на компьютере

Избранные агенты, настройки Rank Checker и отметка о принятии условий хранятся только на этом компьютере и никуда не отправляются. Проверка обновлений обращается к релизам GitHub репозитория Nanda070/VALORANT-Utils.
